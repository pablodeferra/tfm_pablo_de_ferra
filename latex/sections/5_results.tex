\section{Results}
\label{sec:results}

In the following subsections we first present the results obtained on simulated data and then the results for observational data, applying the three procedures described previously (Section \ref{sec:fitting_methods}).

\subsection{Simulated data}

We compute the angular power spectra from the PySM simulated maps. Below we present the simulated-data results organised by fitting method: power-law fits with $\Delta\ell = 10$ and $\Delta\ell = 20$, and the bin-to-bin analysis with $\Delta\ell = 20$.


\subsubsection{Power-law fit ($\Delta\ell = 10$)}
The MCMC fitting of the $\Delta\ell = 10$ spectra yields posterior distributions shown in the corner plots of Figure~\ref{fig:corner_sd_ee_sim} (EE mode) and Figure~\ref{fig:corner_sd_bb_sim} (BB mode). These plots illustrate the parameter constraints and correlations for the synchrotron and dust components.

\begin{figure*}[h]
    \centering
    \includegraphics[width=\linewidth]{corner/corner_sync_dust_cross_EE_sim.pdf}
    \caption{Corner plot showing posterior distributions for synchrotron and dust model parameters from MCMC fitting of simulated EE mode data using $\Delta \ell = 10$.}
    \label{fig:corner_sd_ee_sim}
\end{figure*}

\begin{figure*}[h]
    \centering
    \includegraphics[width=\linewidth]{corner/corner_sync_dust_cross_BB_sim.pdf}
    \caption{Corner plot showing posterior distributions for synchrotron and dust model parameters from MCMC fitting of simulated BB mode data using $\Delta \ell = 10$.}
    \label{fig:corner_sd_bb_sim}
\end{figure*}
