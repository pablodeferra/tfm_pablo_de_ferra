\section*{MCMC Fitting}

The total angular power spectrum between frequencies $\nu_i$ and $\nu_j$ is modeled as the sum of synchrotron, dust, and synchrotron--dust cross-correlation components, 

\begin{equation}
C_\ell(\nu_i, \nu_j) = C_\ell^{\rm sync}(\nu_i, \nu_j) + C_\ell^{\rm dust}(\nu_i, \nu_j) + C_\ell^{\rm sd}(\nu_i, \nu_j),
\end{equation}
where the synchrotron term is
\begin{equation}
C_\ell^{\rm sync}(\nu_i, \nu_j) = A_s \left(\frac{\ell}{\ell_{\rm ref}}\right)^{\alpha_s} 
\left(\frac{\nu_i}{\nu_{\rm ref}}\right)^{\beta_s} \left(\frac{\nu_j}{\nu_{\rm ref}}\right)^{\beta_s},
\end{equation}
the dust term is
\begin{equation}
C_\ell^{\rm dust}(\nu_i, \nu_j) = A_d \left(\frac{\ell}{\ell_{\rm ref}}\right)^{\alpha_d} 
S(\nu_i, \nu_0, \beta_d, T_d) \, S(\nu_j, \nu_0, \beta_d, T_d),
\end{equation}
with the modified blackbody scaling
\begin{equation}
S(f, \nu_0, \beta_d, T_d) = \frac{B_\nu(f, T_d)}{B_\nu(\nu_0, T_d)} \left(\frac{\nu}{\nu_0}\right)^{\beta_d},
\end{equation}
and the cross-correlation term is
\begin{equation}
C_\ell^{\rm sd}(\nu_i, \nu_j) = \rho \sqrt{A_s A_d} \left[ S_s(\nu_i) S_d(\nu_j) + S_s(\nu_j) S_d(\nu_i) \right] 
\left(\frac{\ell}{\ell_{\rm ref}}\right)^{(\alpha_s + \alpha_d)/2},
\end{equation}
where $S_s(f) = (\nu / \nu_{\rm ref})^{\beta_s}$ and $S_d(\nu) = S(\nu, \nu_0, \beta_d, T_d)$ denote the synchrotron and dust frequency scalings, respectively. 
Here, $A_s$ and $A_d$ are the amplitudes of the synchrotron and dust components at the reference multipole $\ell_{\rm ref}$ (taken as 80) and frequencies $\nu_{\rm ref}$ (11.1 GHz) and $\nu_0$ (353.0 GHz), 
$\alpha_s$ and $\alpha_d$ are the multipole spectral indices, $\beta_s$ and $\beta_d$ the frequency spectral indices and $T_d$ the dust temperature.

\paragraph{}

We perform a Markov Chain Monte Carlo (MCMC) fitting procedure to model the total angular power spectrum across multiple frequency bands, using the synchrotron, dust, and synchrotron--dust cross-correlation model described above. Specifically, we fit simulated sky maps from the following frequency bands: QUIJOTE 11~GHz; WMAP 23, 33, 41, 61, and 94~GHz; and Planck 30, 44, 70, 100, 143, 217, and 353~GHz in the multipole range of $30 < \ell < 200$. These maps are generated using the \texttt{Python} library \texttt{PySM}, including all the radiation components of the sky. These maps have been smoothed using the beam window functions provided by each experiment. The resulting posterior distributions are visualized in the corner plots: Figure~\ref{fig:corner_sd_ee} for the EE mode and Figure~\ref{fig:corner_sd_bb} for the BB mode, showing the constraints on the synchrotron and dust parameters and their correlations.

\paragraph{}

The most interesting thing to see is that we are obtaining an $\alpha_s$ of -2.385 for the EE- and -2.126 for the BB-mode instead of the expected value of -3 for the synchrotron emission. Also, in the EE-mode, we are obtaining a $\beta_d$ of 1.40 in contrast of the expected 1.54, characteristic of the polarized dust emission.

In order to study the origin of this value of $\alpha_s$, we considered various options. First, we tested the possibility of a problem in the new model or in the new MCMC fitting program. We tested to run just a synchrotron model (excluding any dust or correlation from the model previously explained) using the 11, 23 and 30 GHz (auto- and cross-) data for the fit. The results are presented in Figure \ref{fig:corner_synch}, where we can see that we are obtaining very similar values of $\alpha_s$, being -2.478 for the EE- and -2.460 for the BB-mode. So in this way we can see that this $\alpha_s$ value is not a consequence of any flattening caused by the dust data. Furthermore, we ran this MCMC fitting using the data obtained last year using this same mask, in the wide survey analysis of the polarized synchrotron emission using the 11 GHz band from QUIJOTE, 23 GHz from WMAP and 30 GHz from Planck- We obtained the same results as we did in that previous study, so we can conclude that this $\alpha_s$ value does not appear as a consequence of the model or the program. 

\paragraph{}

Second, we added a constant term for each band of this synchrotron-only fitting as we did in the wide survey study. The results obtained in this case are compatible with those presented in Figure \ref{fig:corner_synch} for all polarization modes. Additionally, all constant terms obtained are compatible with 0 at a $2\sigma$ level.

As the fitting does not seem to be the problem, we compared the spectra to fit with that obtained in the wide survey study previously mentioned. In Figure \ref{fig:auto_cross_sim_ws} we compare the auto- and cross-spectra obtained in both cases. We can see that these spectra seem to be similar but there is a tendency of the simulated spectra to be greater at smaller angular scales. This is the most likely reason that could be leading to this difference in $\alpha_s$.

We have to find the origin of this flattening of the spectra. For this purpose, we ran the code again using the same data as we used for the wide survey analysis. This is: the real sky data in the 11, 23 and 30 GHz bands and the realistic noise simulations. A comparison between the spectra obtained using this new program and that from the wide survey study is presented in Figure \ref{fig:auto_cross_ws_new}. As one can see, the spectra are identical, so we can conclude that the computational and correction processes are no responsible of the $\alpha_s$ flattening. Also, the MCMC fitting has been carried out using both data, resulting in identical parameters for the synchrotron model,

To conclude this section, the only remaining variables that can be responsible for the stronger spectra behavior observed in Figure \ref{fig:auto_cross_sim_ws} have to be the simulated maps. Figure \ref{fig:spectra_noise_sim_new} compares: the uncorrected spectra $C_{\ell}$ of the simulated sky maps, and that of the real sky maps; the noise spectra $N_{\ell}$ of the white noise, and the realistic noise realizations. As one can see, there are no important differences between simulated and real sky spectra. The most interesting thing to note is that the simulated maps spectra seem to be equal to the real maps or even higher in the case of WMAP at $\ell < 100$. This is interesting as the noise added to the simulated maps was white noise. Therefore it does not strongly affect this range, and one should expect to observe stronger spectra for the real map as in this case we have the signal of the sky + the $1/f$ noise component. May this be the cause of the flat spectra? Could it be resolved by accounting a $1/f$ noise component also for the simulated maps analysis?
